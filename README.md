# Портативный Менеджер Паролей

Простой десктопный менеджер паролей на C# и WPF.

## Возможности

- Создание мастер-пароля с валидацией сложности
- Шифрование данных AES-256-GCM
- Генератор надёжных паролей (12-25 символов)
- Список сохранённых паролей с копированием в буфер
- Портативность — работает с флешки без установки

## Технологии

- C# / .NET 9
- WPF 
- AES-256-GCM шифрование
- PBKDF2 (600 000 итераций)

## Запуск

### Требования
- Windows 10/11 x64
- .NET 9 Runtime (или портативная версия)

### Из исходников
```bash
git clone <repo-url>
cd PasswordManager
dotnet build
dotnet run
```
